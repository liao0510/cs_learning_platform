專案文件

透過固定規則與資料結構，讓 AI 能穩定新增內容而不破壞原本的網站。

網站架構與擴充方式

六大主分類對應 data/categories.json；35 個子分類對應 data/subcategories.json；所有上線單元的索引位於 data/topics.json；完整教學內容位於 data/lessons/。

1. 選分類從分類 JSON 中挑選分類與子分類 slug。
2. 新增文章建立 lessons/<id>.json，再新增 topics.json 對應索引。
3. 自動使用模板文章渲染器會呈現段落、圖解、測驗與公式計算器。

公式與計算器規範

凡涉及可計算數值的公式，除標示各變數與單位，也應配置互動工具。計算邏輯集中在 js/components/calculator.js，並由 tests.mjs 驗證。

詳細規範請參閱儲存庫根目錄 AGENTS.md；安裝與上線說明請參考 README.md。
